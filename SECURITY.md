# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Aureus Protocol, please report it privately.

**Do not** open a public issue. Email or DM the maintainer directly.

## Process

1. Report received → acknowledged within 48 hours
2. Investigation & impact assessment → 3-5 business days
3. Patch development & testing
4. Coordinated disclosure with users

## Scope

- All contracts in `contracts/`
- Deploy scripts and configuration
- Off-chain infrastructure

## Out of Scope

- Front-end UI (not part of this repo)
- Third-party dependencies (report upstream)

## Bug Bounty

Contributors who find and responsibly disclose critical vulnerabilities may be eligible for rewards. Contact maintainer for details.
